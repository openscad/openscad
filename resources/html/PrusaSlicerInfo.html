Open the rendered model directly in PrusaSlicer. If PrusaSlicer is already running, the model is loaded into the open window.

PrusaSlicer is detected automatically (native install, Flatpak, AppImage, Snap, macOS application or Windows installer). To use a specific installation, set its path in Preferences → 3D Print → PrusaSlicer.

3MF is recommended: it keeps colors and multiple objects.
